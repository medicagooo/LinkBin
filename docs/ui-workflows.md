# 界面与文件操作

`src/ui.ts:renderIndexPage` 输出完整页面，并嵌入 `src/ui-workflows.ts` 中的脚本、样式和四语言文案。页面仍从同一个 Worker 加载，管理请求仍由现有会话检查保护。

导航分为文件、下载链接、合并文件、采集记录、主机与规则。切换只隐藏对应面板，保留填写内容；主机表单另外记录是否展开。认证门关闭时整个工作区隐藏。

`loadSection` 给每个数据区域分配递增请求号，只有最新回复可更新该区域。首次加载显示等待状态，失败显示原因与重试按钮。替换查询先清除旧分页并重置偏移量；文件列表追加分页失败保留已显示的结果，重试同一页。分享选择器读取最多 200 个可用文件，超过后提示缩小搜索；文件行的分享入口可带入该行，避免它落在首屏范围之外。删除成功后刷新选择器和合并状态，清除已失效的分享选择。

上传保持串行。选择文件后列出名称、大小和处理状态；超过 100 MiB 的文件不会提交。成功项释放 File 引用，失败项保留，重试只重新发送失败项。容量提醒使用最近读取的剩余容量，最终是否接纳仍由服务端决定。页面显示处理数量，不声称获得了字节进度。

密码分享仍绑定版本并遵守已有有效期与密码规则，直链仍跟随连续更新的最新版本且可撤销。复制先等待剪贴板结果，失败时尝试浏览器复制命令；两者失败时显示可选中的只读内容，供手动复制。

合并预览验证当前定义，编辑任一字段会使预览确认失效。只有当前定义预览成功才可保存，保存与运行分别反馈。八来源预设检查路径是否唯一可用，完整内容仍由后端预览验证。已有结果可直接下载。

采集请求显示真实回执，包括连接失败、部分失败、到预算续跑及没有可执行主机。前端等待时间为六分钟，对应 `src/index.ts` 中五分钟的执行预算并留出返回时间；请求断开不能证明服务端停止，因此提示先刷新历史，不自动重试。结束后刷新文件、容量、回执、新鲜度、合并和链接列表。

离线验证：`pnpm test:ui` 执行输出脚本的行为回归；`pnpm test` 同时运行 UI 回归和既有 Workers 模拟 D1/R2 测试。`node scripts/preview-ui.mjs` 仅在回环地址提供可视化样本，不连接线上服务。当前脚本使用本机 bundled Node 24 的 TypeScript 擦除能力。

未增加接口、迁移、部署秘密、上传代码执行能力或云控制台级对象管理。
